
# Vastu Plot + Chakra

Simple Android app:

1. Plot photo select करें.
2. Plot boundary पर जितने चाहें red dots लगाएँ.
3. Dots को drag करके exact जगह set करें.
4. Delete mode में dot पर long-press करके हटाएँ.
5. Mobile gallery से कई Chakra photos एक साथ select करें.
6. हर Chakra अलग page पर दिखाई देगा.
7. हर page पर पहले plot photo और उसके नीचे Chakra photo दिखाई जाएगी.

## GitHub APK

Repository में files upload करें:

- Run workflow
