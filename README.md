# Vastu Plot + Chakra PDF App

- Plot photo as background.
- Unlimited editable red boundary dots.
- Plot/North degree.
- Select a mobile folder named CHKRA and load all PNG/JPG/WEBP images.
- Refresh folder after adding new chakra images.
- Every chakra is overlaid on the same plot photo.
- Plot degree sets the initial chakra degree.
- Manual chakra rotation with slider and +/-1°.
- PDF: page 1 client name/address/mobile + plot; then one page per chakra with plot + chakra overlay.
- Footer/name: Ghanshyam Lohani.
